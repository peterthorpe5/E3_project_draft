# Example resources

- `synthetic_demo`: three explicitly synthetic models, illustrative pockets,
  known-transform comparisons, MSA, NJ tree and offline viewer pages.
- `maddy_report_project`: the user's completed 60-model BRCA1 report imported
  into the app schema. It contains real report evidence but no coordinates or
  FASTA. Add the original models/FASTA, or import the complete HPC results folder,
  to enable structure comparisons and sequence analysis.

Each directory can be opened directly with `pocket-workbench app --resource`.

Version 1.1 includes synthetic_review.zip: extract it and open index.html for a complete offline example. The synthetic native resource includes real USalign/TMalign test transforms and explicitly illustrative pocket scores.
