# Coordinated app release handover

Release components:

- R Shiny reporter: `0.11.0`
- Python Streamlit reporter: `0.8.0`
- Structural-alignment pocket-review generator: `0.4.0`

## Implemented behaviour

Both apps now provide:

- expanded HOG/root-orthogroup metrics for input sequence memberships, species,
  total groups, groups linked to inherited E3 seed evidence, groups containing
  all input species, and the largest group;
- exact required-species, species-breadth, inherited-seed, curated taxonomy-role
  and NCBI-taxon filters;
- full OrthoFinder group-size distributions, including a separate category for
  groups containing members from one species only;
- a Seed & HOG explorer accepting one or several seed identifiers with Any/All
  matching, matching-group summaries, group and species filters, associated
  evidence, TSV/Excel tables and filtered member protein FASTA;
- selected-group MAFFT alignment FASTA export; and
- PDF export for every active native application graph.

Pocket-review pages generated by structural-alignment `0.4.0` additionally
contain offline **Download current view PDF** and **Download alignment PDF**
controls. The former records the currently selected protein/pocket and rotated,
zoomed canvas. The latter paginates the complete published MAFFT alignment.

Seed status remains explicitly an inherited prior-evidence label. It is not
treated as proof of E3 function. Taxonomy filtering uses only the shipped
13-row curated manifest; unmatched OrthoFinder labels remain unclassified.

## R v0.10.6 regression repaired

`prepare_final_gate_druggability_data()` now restores the public `cluster_id`
field after its differently named join key is consumed by `dplyr::inner_join()`.
This directly addresses both previously reported assertions:

- individual selection returns `cluster_2`; and
- the bounded comparison returns `cluster_1, cluster_1`.

## Runtime note

Plotly-native PDF exports use Kaleido. Python declares
`kaleido>=0.2.1,<1`; the Shiny environment should include
`python-kaleido=0.2.1`. ggplot-based Shiny exports use R's PDF device.

Existing pocket-review bundles remain readable and retain alignment FASTA
export when their sequence table contains `aligned_sequence`. Regenerate the
pocket-review bundle with structural-alignment `0.4.0` to add the two direct PDF
buttons inside the 3D/alignment report itself.
