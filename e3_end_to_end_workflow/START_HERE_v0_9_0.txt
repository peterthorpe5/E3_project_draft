E3 PROJECT DRAFT: COMPLETE SOURCE PACKAGE
=========================================

Release: 0.9.0
Prepared: 27 July 2026
Project: PT_E3_6 / ARIA plant E3

PURPOSE
-------

This is a consolidated, self-contained source package. It replaces the need to
combine the earlier v0.8.0 and v0.9.0 update archives manually.

Unpacking the ZIP creates exactly one top-level directory:

    E3_project_draft/

There is no second, nested E3_project_draft directory.

WHAT IS INCLUDED
----------------

    E3_shiny_app                    R Shiny reporting application
    e3_discovery_engine             E3 discovery workflow
    e3_end_to_end_workflow          Master workflow, version 0.9.0
    e3_ligandability_pipeline       Ligandability workflow
    e3_orthology_integration        Orthology integration workflow
    e3_python_app                   Python reporting application
    e3_source_to_parquet_seed       Candidate-evidence construction
    e3_structural_alignment         Optional structural-alignment workflow
    expression_downloader           Expression Atlas acquisition and conversion
    docs/                           Printable operator guides and handovers
    docs_site/                      Source for the searchable documentation site
    .github/workflows/docs.yml      GitHub Pages documentation workflow
    tests/                          Repository-root tests

The v0.8.0 and v0.9.0 release-validation records and operator guides are both
retained. The detailed 27 July 2026 handover is under docs/handovers/.

PRIMARY ENTRY POINTS
--------------------

From this directory, a normal Slurm-controlled run is submitted with:

    ./run_e3_pipeline.sh \
        --mode slurm \
        --config e3_end_to_end_workflow/config/my_immutable_run.yaml \
        --max-jobs 4 \
        --account barton \
        --partition general \
        --resume

A strict new run from fresh inputs is submitted with:

    ./run_e3_pipeline_fresh.sh \
        --config e3_end_to_end_workflow/config/my_fresh_run.yaml \
        --mode slurm \
        --threads 32 \
        --max-jobs 10 \
        --account barton \
        --partition general

For a computer without Slurm:

    ./run_e3_pipeline.sh \
        --mode local \
        --config e3_end_to_end_workflow/config/my_immutable_run.yaml \
        --threads 8 \
        --resume

Read README.md and docs/E3_PROJECT_OPERATOR_GUIDE_v0_9_0.pdf before preparing a
production configuration.

VALIDATION
----------

Run the repository checks from this directory:

    ./run_repository_tests.sh

Run the master-workflow quality gate with:

    cd e3_end_to_end_workflow
    ./run_tests.sh

Each component package also contains its own README and test entry point.

IMPORTANT BOUNDARY
------------------

This archive consolidates the code and documentation already developed for
v0.9.0. It does not silently introduce a new scientific algorithm or claim to
repair the unresolved stage-07 Expression Atlas scalability failure described
in the 27 July 2026 handover. That failure requires Slurm accounting and worker
log evidence before a defensible correction can be versioned.

NOT INCLUDED
------------

Large biological datasets, downloaded Expression Atlas resources, OrthoFinder
results, completed analysis runs, Conda environments, scheduler logs, caches,
temporary build trees and duplicate backup directories are intentionally not
embedded. The configuration files refer to these external authorities by
reviewed paths and checksums.

PACKAGE INTEGRITY
-----------------

FILE_MANIFEST_v0_9_0.tsv records the relative path, size and SHA-256 checksum
for every packaged file except the manifest itself.
