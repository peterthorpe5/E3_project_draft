How to read the rankings

The ranked cavities are fpocket predictions, ordered within each model by P2Rank rescoring. If rescoring fails or is disabled, the ranking basis explicitly changes to fpocket druggability. Independent P2Rank predictions are shown separately. Scores from different methods have different meanings and are not combined.

Local pLDDT helps assess the predicted pocket geometry. It does not establish the relative placement of distant domains. Pocket scores identify candidate small-molecule binding sites; they do not establish binding, affinity, selectivity or therapeutic efficacy. The rescore_2024 profile is experimental.

Original chains, residue numbers, insertion codes and any FASTA positions are retained in the Excel residue sheets and TSV tables. Models use protein heavy atoms only; waters, metals and other non-protein components are excluded. No confidence trimming, PAE analysis or docking is performed.

Model files and checks

Download each model's workbook or inspect the prepared structure. Tool folders contain TSV predictions and portable PyMOL/ChimeraX visualisations generated by P2Rank.

Methods: fpocket, fpocket druggability, P2Rank. This report works offline; keep the result folders beside it to use the file links.
