Choose a model or sequence and download its exact saved inputs. Public accession links open separate database records. Local files and pocket annotations are transferred only when you load them in the external website.

Model inputs preserve retained-region sequences. FASTA-only records use their own saved sequence. Populated EMERALD links use public canonical UniProt sequences, which can differ from local model inputs.

Reuse a saved structural alignment

The reference file and already-transformed mobile retain the saved fit. No new structural alignment is run here. The recorded input region and tool remain explicit.

Prepared group model ZIPs

Download a group ZIP and upload it manually to the Multi-Model Inspector. Read its manifest and HANDOFF.txt where supplied. Group members may be distinct sequences rather than alternative predictions of one protein. PAE and AF3-specific summary metrics are not supplied.
