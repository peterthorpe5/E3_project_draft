ARIA plant E3 Shiny reporter v0.13.0 validation hand-off
=======================================================

Scope
-----

This release mirrors Python reporter v0.10.0: complete human-containing HOGs,
the curated plant-and-human subset, and replacement pasted-list multi-field
search with source provenance.

Checks completed in this build workspace on 2026-08-13
------------------------------------------------------

- New query builders have defensive view, matching-mode and row-bound checks.
- Representative DuckDB tests exercise ranked/unranked and human/plant HOG
  definitions, plus cross-schema search result binding.
- UI-contract tests cover lazy HOG loading, all requested downloads and the
  complete-resource search controls.
- Search source fields are cast to character before `dplyr::bind_rows()`,
  preventing logical/character prototype conflicts.
- `git diff --check` reports no whitespace errors.

Environment limitation
----------------------

This build environment does not contain R, Rscript, DuckDB or duckplyr, so the
complete R suite cannot be executed honestly here.

Required release gate
---------------------

    cd E3_shiny_app
    Rscript inst/scripts/check_dependencies.R
    Rscript inst/scripts/run_tests.R

The two `test_script_utils.R` skips are expected when the R session supplies no
`--file` argument. Any actual failure blocks release.
