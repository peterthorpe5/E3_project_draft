ARIA plant E3 Shiny reporter v0.6.0 test note
================================================

The package includes the expanded test suite under tests/testthat/.

Validation completed for v0.5.0 in this development environment:
- Every v0.5.0 R source and test file parsed without syntax errors using the
  tree-sitter R grammar.
- The generated evolutionary-group de-duplication SQL was executed against a
  small DuckDB fixture and returned the expected group counts.
- The pre-structure/structural threshold SQL design was executed against a
  four-group DuckDB fixture. It classified the 0.325 minimum-druggability case
  as a near-miss at 0.50 and a pass at 0.30.

Environment limitation:
- R is not installed in the sandbox environment, so I could not execute the R
  testthat suite or an R-native parse of the additive v0.6.0 files here.
- All 40 R source/test files, including the v0.6.0 additions, passed a static
  delimiter, quote and escape scan. The source also passed repository
  whitespace/error validation with `git diff --check`; its complete testthat
  run remains required on the Mac or cluster R environment.
- Run the complete suite in the e3_shiny_app conda environment with:

    Rscript inst/scripts/check_dependencies.R
    Rscript inst/scripts/run_tests.R

- rejection of incomplete bundles, ambiguous discovery and unsafe page paths;
- stable group labels and rank ordering;
- retention of model and OrthoFinder-group member sequence identifiers;
- separate structure and MAFFT-alignment tab contracts;
- the new command-line configuration field; and
- retention of every pre-existing application tab.
