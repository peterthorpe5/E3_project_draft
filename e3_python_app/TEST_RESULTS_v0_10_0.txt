ARIA plant E3 Python reporter v0.10.0 validation hand-off
========================================================

Scope
-----

This release adds complete human-containing HOG exploration, its curated
plant-and-human subset, and replacement batch multi-field search.

Checks completed in this build workspace on 2026-08-13
------------------------------------------------------

- All Python source and test files compile with `python -m compileall`.
- Edited Python files meet the 100-character PEP 8 line-length target.
- `git diff --check` reports no whitespace errors.
- Focused tests cover human-only, plant-human, plant-only, ranked and unranked
  HOGs; human aliases; available protein sequences; every co-member; list
  parsing; smart/exact/contains search; row bounds; unlike relation schemas;
  and headless tab/search wiring.
- Search values are bound in Python SQL rather than interpolated.
- HOG membership is explicitly limited to root-level `N0.HOG…` identifiers.

Environment limitation
----------------------

This build environment does not contain DuckDB, pytest, Streamlit or Plotly,
so the complete Python suite cannot be executed honestly here.

Required release gate
---------------------

    cd e3_python_app
    python -m pip install --editable '.[dev]'
    ./run_tests.sh

Any actual test failure blocks release. Dependency deprecation warnings alone
do not constitute a failed scientific or application assertion.
